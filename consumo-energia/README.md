# ⚡Calculadora de consumo elétrico inteligente

## 🎯Objetivo do programa
Projeto desenvolvido com o objetivo de ajudar usuários a estimar quanto um aparelho gasta de energia elétrica por mês, com base em dados simples de uso.

## 💻Linguagens utilizadas
Python.

## 🧮Fórmula utilizada para o cálculo
Para se chegar ao resultado de consumo médio mensal, o programa utiliza a seguinte fórmula:</br>

**consumoMedio** = (**potencia** * **horasDia** * 30) / 1000 </br>

 Onde:
 1. **potencia**: Variável que se refere à potência do aparelho.
 2. **horasDia**: Variável que se refere à quantidade de horas diárias de uso do aparelho.

As duas variáveis são multiplicadas entre si e, em seguida, multiplicadas por 30 (quantidade de dias em um mês comercial). Em seguida, o produto é dividido por 1000.

## 📃Instruções de execução do programa
1. Informar o aparelho;
2. Informar a potência do aparelho em números apenas;
3. Informar a quantidade de horas de uso em números apenas;
4. Tecle "Enter";
5. O programa retornará a média de gasto por mês em kWh (kiloWatt-hora).
