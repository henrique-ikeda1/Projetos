# 🚿 Monitor de consumo inteligente da água

## 🎯Objetivo do programa
Projeto desenvolvido com o objetivo de conscientizar usuários sobre o consumo de água.

## 💻Linguagens utilizadas
Python.

## 📃Instruções de execução do programa
1. Informar o tipo de imóvel;
2. Informar o consumo de água em m³;
3. Tecle "Enter";
4. O programa vai cruzar o tipo de imóvel com o m³ informado e retornar o nível de consumo de água.
