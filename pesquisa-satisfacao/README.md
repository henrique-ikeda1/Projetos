# Programa de pesquisa de satisfação com atendimento

## 🎯Objetivo do programa
Projeto desenvolvido com o objetivo de coletar opiniões acerca de um atendimento realizado com 50 clientes.

## 💻Linguagens utilizadas
Python.

## 📃Instruções de execução do programa
1. Ao rodar o programa, um formulário numerado aparecerá na tela;
2. Informar o nome do(a) entrevistado(a);
3. Informar a idade do(a) entrevistado(a);
4. Informar a opinião conforme as opções disponíveis (1-EXCELENTE, 2-BOM ou 3-RUIM);
5. Tecle "Enter";
6. A resposta será armazenada e um novo formulário de entrevistado aparecerá;
7. Após as 50 entrevistas, o programa exibirá a contagem de votos EXCELENTE e RUIM.
