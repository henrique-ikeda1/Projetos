# 💧 Sistema de monitoramento dos níveis de água de um reservatório

## 🎯Objetivo do programa
Projeto desenvolvido com o objetivo de monitorar o nível de água de um reservatório, exibindo alertas com cores de acordo com a gravidade da situação.

## 💻Linguagens utilizadas
Python.

## Explicando como o programa funciona
1. Ao inicializar o programa, ele fará uma quantidade pré-definida de até 10 leituras consecutivas, com intervalo de 5,5 segundos entre cada leitura;
2. A leitura é feita de forma aleatória;
3. Ao definir qual nível será exibido, ele define a mensagem e a cor da mesma, conforme nível do reservatório;
4. Após cada leitura, o estilo padrão é redefinido e a mensagem apagada;
5. Finalizada a 10ª leitura, ele exibe uma mensagem informando que o monitoramento foi concluído.
